# Tarea 3 – Procesamiento de Datos con Apache Spark

## Descripción del proyecto
Este repositorio contiene el código fuente desarrollado para realizar el análisis de un conjunto de datos mediante procesamiento batch con Apache Spark, como parte de la Tarea 3 del curso de Big Data de la UNAD.

## Objetivo
Procesar y analizar el conjunto de datos seleccionado mediante Apache Spark para obtener resultados relevantes a partir de los datos.

## Tecnologías utilizadas
- Python
- Apache Spark
- PySpark

## Archivo principal
- `tarea3_batch (1).py`: código fuente utilizado para ejecutar el análisis batch.

## Instrucciones de ejecución
1. Disponer de un entorno con Python, Apache Spark y PySpark correctamente configurados.
2. Descargar el archivo de código fuente de este repositorio.
3. Verificar y ajustar la ruta del conjunto de datos utilizado, según el entorno de ejecución.
4. Ejecutar el programa desde la terminal con el comando correspondiente:

```bash
spark-submit "tarea3_batch (1).py"
```

## Resultados
Los resultados del procesamiento se obtienen al ejecutar el código. La demostración de su funcionamiento y los resultados obtenidos se presentan en el video explicativo de la actividad.
